# Академічний регламент та правила підготовки статті (RULES.md)

Цей документ містить повний звід вимог, стилістичних обмежень, структурних стандартів та термінологічних правил для підготовки рукопису наукової статті за матеріалами дослідження в межах проєкту `isosurface-extraction-comparison`.

Вимоги базуються на нормативних документах редакції (`article_rules/Зразок_рукопису.docx`, `article_rules/Пример чек лист.docx`), стандартах наукової періодики, що індексується у Scopus / Web of Science, та первинних публікаціях предметної галузі.

> **Оформлення та складання рукопису** (розмітка стилями шаблону Springer Nature, правила для рисунків, таблиць, формул, цитувань, а також правила майбутнього перекладу англійською) винесено в окремий документ — [RULES-SPRINGER.md](RULES-SPRINGER.md). Цей документ регламентує **зміст**, `RULES-SPRINGER.md` — **форму**.

## 1. Загальні та організаційні обмеження

1. **Локація матеріалів**: Усі матеріали, що стосуються фінального рукопису статті, зберігаються **виключно в директорії `article/`**:
   - Розділи статті у форматі Markdown (`article/01-vstup.md`, `article/02-ohlyad.md`, ..., `article/07-vysnovky.md`).
   - Графіки, схеми, діаграми та рендери — у підкаталозі `article/assets/` (або `results/`).
   - Додаткові таблиці, зведені чек-листи та додатки — у межах `article/`.
2. **Сувора верифікація літератури (Нульова толерантність до галюцинацій)**:
   - Будь-яке посилання на літературу повинно підтверджуватися реальним первинним документом або верифікованим ідентифікатором (DOI, arXiv ID).
   - Усі посилання мають базуватися на фізичних PDF у директорії `articles_pdf/` або на офіційних наукових базах (Scopus, WoS, IEEE Xplore, ACM Digital Library).
   - Усі джерела зведені в **єдиний файл** `article/08-literatura.md`: нумерований список літератури плюс службовий реєстр верифікації «Верифікація джерел» (робота, що підтверджує, розділи-споживачі, наявність первинного файлу). Окремих таблиць джерел у розділах не ведеться; реєстр до редакції не потрапляє.
3. **Автономність агента**:
   - У межах директорії проєкту агент має право виконувати всі необхідні дії (читання, запис, скрипти, обчислення) автономно без нав'язливих проміжних перепитувань.

## 2. Мовні, граматичні та типографічні вимоги

1. **Категорична заборона присвійних займенників («ми-парадигми»)**:
   - **ЗАБОРОНЕНО**: «ми отримали», «нами розроблено», «ми досліджуємо», «на наш погляд», «наша модель», «нами проведено».
   - **ОБОВ'ЯЗКОВО**: безособова форма та пасивний стан: *«отримано»*, *«досліджено»*, *«встановлено»*, *«запропоновано»*, *«показано»*, *«сформовано»*.
2. **Типографіка тире та дефісів**:
   - Між числовими діапазонами ставиться виключно коротке тире «–» (en-dash) **без пробілів**: `14–16°`, `32–64`, `2–5 мм`, `2015–2025`. Дефіс `2-5` або довге тире з пробілами `2 — 5` заборонені.
   - У тексті як розділовий знак вживається коротке тире «–» з відступами з обох боків.
   - Дефіс «-» використовується лише у складних словах: *«інженерно-технічний»*, *«скінченно-різницевий»*.
3. **Лапки та спеціальні символи**:
   - В україномовному тексті використовуються виключно кутові лапки-ялинки `«...»` (лапки `\"...\"` заборонені).
   - Символ градуса вставляється строго спеціальним символом `°` (`°C`, `10°`), а не верхнім індексом літери `o`.
4. **Синтаксичні обмеження**:
   - Довжина речення не повинна перевищувати 25–30 слів.
   - Будь-якій абревіатурі повинна передувати повна розшифровка при першому згадуванні: *«метод скінченних елементів (МКЕ)»*, *«конструктивна твердотільна геометрія (CSG)»*, *«функція квадратичної похибки (QEF)»*.
5. **Вживання терміна «sliver»**:
   - Термін для позначення вироджених тонких елементів з критично малими кутами завжди пишеться **англійською мовою**: **sliver** (наприклад: *«sliver-елемент»*, *«sliver-трикутники»*, *«частка sliver-елементів»*). Написання кирилицею («слівер») заборонено.

## 3. Структура рукопису (7-розділова схема фахового журналу)

Стаття повинна відповідати 7-розділовій структурі з жорсткою наскрізною причинно-наслідковою відповідністю:

### 3.1. Заголовок та метадані статті
- **УДК**: Обов'язкове зазначення відповідного коду класифікатора на початку рукопису.
- **Назва статті** (українською та англійською мовами):
  - Назва має орієнтувати на **результат**, а не на процес!
  - **Заборонені слова**: *«Дослідження...»*, *«Аналіз...»*, *«Вивчення...»*.
  - **Рекомендовані формулювання**: *«Закономірності...»*, *«Виявлення впливу...»*, *«Підвищення якості...»*, *«Метод...»*.
- **Відомості про авторів**:
  - Українською: Ініціали та Прізвище (наприклад: *А. Б. Лісняк, Р. О. Котов, С. В. Чопоров*).
  - Англійською: Повне Ім'я та Прізвище (наприклад: *Andrii Lisniak, Roman Kotov, Serhii Choporov*).
  - Обов'язкове зазначення афіліації, адрес та ORCID.

### 3.2. Резюме та ключові слова
- **Обсяг резюме**: 1800–1900 знаків із пробілами, курсивом (українською та англійською).
- **Обов'язкова 6-компонентна структура резюме**:
  1. *Об'єкт дослідження*.
  2. *Проблема, що вирішувалася*.
  3. *Суть отриманих результатів* (обов'язково з **конкретними числовими показниками**!).
  4. *Стисла інтерпретація* (чим ці результати пояснюються).
  5. *Особливості та характерні відмінності* перед відомими рішеннями.
  6. *Сфера та умови практичного застосування*.
- **Ключові слова**: рівно 10 термінів, розділених комами.

### 3.3. Розділ 1. Вступ
- Обґрунтування актуальності **наукової проблематики/тематики**, а не самої статті.
- Відповідь на два ключові запитання:
  1. *Навіщо за сучасних умов потрібно проводити дослідження з цієї теми?*
  2. *Що можуть дати інженерній практиці результати цих досліджень?*
- **Обмеження**: обсяг до 1 сторінки; аналіз літератури в цьому розділі не проводиться (лише посилання, що засвідчують важливість теми).
- **Обов'язковий фінал**: завершується висновком:  
  *«Тому дослідження, присвячені [назва тематики], є актуальними.»*

### 3.4. Розділ 2. Аналіз літературних даних та постановка проблеми
- **Критичний аналіз джерел**: щодо кожного джерела (або пари близьких) має бути відповідь на два питання:
  1. *Які питання залишилися невирішеними?*
  2. *Чому вони залишилися невирішеними (об'єктивні та суб'єктивні причини)?*
- **Правило посилань**: у тексті розділу 2 **прізвища вчених не згадуються** (заборонено: «У роботі Іванова...»); посилання оформлюються лише номерами: *«У роботі [19] запропоновано... Проте...»*.
- **Вимоги до списку джерел**:
  - $\ge 60\%$ робіт за останні 5–10 років (2015–2025 рр.).
  - $\ge 60\%$ іноземних джерел.
  - Джерела — виключно наукова періодика Scopus/WoS та профільні монографії (жодних методичок чи навчальних посібників).
- **Обов'язковий фінал**: синтез виявлених недоліків у єдину **загальну невирішену проблему**, яка логічно зумовлює мету дослідження.

### 3.5. Розділ 3. Мета та задачі дослідження
- **Формулювання мети** складається строго з двох взаємопов'язаних частин:
  - *Наукова частина*: орієнтує на очікуваний науковий результат («Метою дослідження є виявлення закономірностей...») і кореспондує з назвою статті.
  - *Практична частина*: вказує на прикладний вихід («Це дасть можливість забезпечити...»).
- **Задачі дослідження**:
  - Від 2 до 5 лаконічних задач (ідеально — по одному реченню кожна).
  - Жодна задача не має дублювати мету або формулюватися як процес.
  - Порядок задач строго визначає структуру розділу 5 та розділу 7.

### 3.6. Розділ 4. Матеріали та методи досліджень
- **Обов'язковий вступний блок**:
  - *Об'єкт дослідження*;
  - *Основна гіпотеза дослідження*;
  - *Прийняті припущення*;
  - *Прийняті спрощення*.
- Описується виключно те, **як** проводилися дослідження: математичний апарат, формули, алгоритми, ґратки, метрики, випробувальний стенд, характеристики обладнання та ПЗ (із зазначенням країни-виробника в дужках).
- **КАТЕГОРИЧНА ЗАБОРОНА**: у розділі 4 не наводиться жоден результат експериментів!

### 3.7. Розділ 5. Результати досліджень [чого?]
- **Назва розділу**: конкретна, із зазначенням предметної суті результатів.
- **Внутрішня структура**: строго симетрична до задач розділу 3:
  - Підрозділ 5.1 $\to$ вирішення Задачі 1;
  - Підрозділ 5.2 $\to$ вирішення Задачі 2;
  - Підрозділ 5.3 $\to$ вирішення Задачі 3.
- Поміж заголовком «5. Результати...» та «5.1» **заборонено будь-який вступний текст**.
- **Стиль викладу — «сухий останок»**: коментуються лише фактичні дані таблиць і графіків (на що саме треба звернути увагу).
- **ЗАБОРОНА**: у розділі 5 заборонено інтерпретувати, *чим пояснюються результати* (це виноситься в розділ 6).
- **Правило завершення**: жоден підрозділ не може закінчуватися таблицею чи рисунком — обов'язковий підсумковий текстовий абзац.

### 3.8. Розділ 6. Обговорення результатів дослідження [чого?]
- **Назва розділу**: конкретна, із зазначенням предметної суті.
- Будується строго за 6-компонентною схемою доказової бази наукової новизни:
  1. *Чим пояснюються отримані результати?* (фізико-математична інтерпретація для кожної задачі з посиланням на формули, таблиці та рисунки розділу 5).
  2. *Завдяки яким особливостям забезпечуються переваги перед аналогами?* (порівняння: «На відміну від [19], де..., у даній роботі...»).
  3. *Як отримані результати закривають проблему з розділу 2?* (доказ досягнення мети).
  4. *Обмеження дослідження* (рамки, в яких результати є адекватними).
  5. *Недоліки дослідження* (фактори, що можуть ускладнити використання).
  6. *Перспективи розвитку дослідження* (і аргументація, чому саме вони).
- **ЗАБОРОНЕНІ МАРКЕРИ**: заборонено вживати фрази *«науковою новизною є»*, *«вперше отримано»*, *«дістали подальшого розвитку»*. Доказом новизни є логіка розділу 6.

### 3.9. Розділ 7. Висновки
- **Кількість висновків строго дорівнює кількості задач**:
  - Задача 1 $\to$ Підрозділ 5.1 $\to$ **Висновок 1**;
  - Задача 2 $\to$ Підрозділ 5.2 $\to$ **Висновок 2**;
  - Задача 3 $\to$ Підрозділ 5.3 $\to$ **Висновок 3**.
- **Вимоги до кожного висновку**:
  - Опис суті отриманого результату.
  - Відмінні риси та переваги перед відомими.
  - Стисла інтерпретація (чим пояснюється).
  - **Обов'язкові конкретні числові та порівняльні оцінки** (відсотки, кути, час, похибки).

## 4. Обов'язкові заключні декларації рукопису

У кінці статті (після розділу 7) обов'язково розміщуються стандартизовані блоки:

1. **Конфлікт інтересів**:
   > *«Автори декларують, що не мають конфлікту інтересів стосовно даного дослідження, в тому числі фінансового, особистісного характеру, авторства чи іншого характеру, що міг би вплинути на дослідження та його результати, представлені в даній статті.»*
2. **Фінансування**:
   > *«Дослідження проводилося без фінансової підтримки.»* (або номер гранту / держтеми).
3. **Доступність даних**:
   > *«Рукопис має пов'язані дані у сховищі даних: вихідний код стенду, геометрії та таблиці метрик розміщено у відкритому доступі в репозиторії проєкту.»*
4. **Використання засобів штучного інтелекту**:
   > *«Автори підтверджують, що генеративні моделі штучного інтелекту використовувалися виключно як допоміжний інструмент під час первинної обробки та систематизації відкритих чисельних результатів експериментів. Усі наукові формулювання, аналітичні висновки та розрахунки верифіковано авторами особисто.»*
5. **Внесок авторів (за таксономією CRediT)**:
   - Із зазначенням конкретного внеску кожного співавтора (концептуалізація, методологія, програмне забезпечення, валідація, редагування).
6. **Література / References**:
   - Наскрізна нумерація джерел за порядком першої появи в тексті.
   - Обов'язкове зазначення DOI для кожної статті у списку References.

## 5. Термінологічний глосарій (Стандарт предметної галузі)

| Термін англійською мовою | Нормативний термін українською мовою | Контекст використання |
|---|---|---|
| *Signed Distance Function (SDF)* | Функція / поле знакозмінних відстаней | Метричне скалярне поле $\|\nabla f\| = 1$ |
| *R-functions theory* | Теорія R-функцій (функцій Рвачова) | Аналітичні CSG-операції над неявними областями |
| *Isosurface Extraction / Polygonization* | Екстракція ізоповерхні / полігонізація | Перехід від $f(\mathbf{x})=0$ до полігональної сітки |
| *Primal method / Dual method* | Прямий метод / двоїстий метод | Класифікація алгоритмів (MC проти DC/DMC) |
| *Quadratic Error Function (QEF)* | Функція квадратичної похибки (QEF) | Мінімізація положення вершини в DC |
| *Centroid vertex placement* | Центроїдне розташування вершин | Двоїсте розміщення вершин у DMC |
| *Sliver triangle / degenerate face* | Sliver-елемент / вироджений трикутник | Елемент із критично малим кутом $\alpha < 10^\circ$ (термін «sliver» вживати строго англійською) |
| *Minimum dihedral / planar angle* | Мінімальний двогранний / плоский кут | МКЕ-метрика обумовленості $\alpha_{\min}$ |
| *Watertight / 2-Manifold mesh* | Герметична / двовимірна багатовидова сітка | Топологічні предикати придатності |
| *Inaccurate normals percentage* | Відсоток кутової похибки нормалей | Відхилення від аналітичного градієнта поля |
| *Differentiable isosurfacing* | Диференційовна екстракція ізоповерхонь | Варіаційні методи типу FlexiCubes, DMTet |
| *Crease / sharp feature preservation* | Збереження ліній зламів / гострих ребер | Відтворення функціональних кутів моделей |
| *Stiffness matrix condition number* | Число обумовленості матриці жорсткості | Показник чисельної стабільності розв'язку МКЕ |

## 6. Чек-лист самоперевірки розділів рукопису

Перед фіналізацією кожного розділу в директорії `article/` необхідно перевірити:
- [ ] Відсутність займенників «ми», «нами», «наш».
- [ ] Заміна дефісів на короткі тире в числових інтервалах (`10–20`, а не `10-20`).
- [ ] Використання лапок-ялинок `«...»`.
- [ ] Всі джерела в розділі 2 цитуються без прізвищ (лише номери `[.]`), для кожного вказано, що не вирішено і чому.
